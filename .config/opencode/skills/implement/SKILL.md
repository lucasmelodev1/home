# Implement

- Reuse code standards from the current file, like naming in classes, functions, variables, etc
- Prioritize readability, a code that junior developers can read and understand
- Reusability is key, use current project dependencies to the fullest
- Do not add any new dependencies unless directly asked to
- Create maintainable code like a senior developer
- Update any markdown files related to the files touched if content is outdated
